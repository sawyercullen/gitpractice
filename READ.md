
# Montana River Adventures Manager

## Business Problem
Montana River Adventures is a rafting outfitter that offers guided rafting trips on rivers around Missoula, Montana. The business needs a better way to manage customer reservations and keep track of rafting trips. This app organizes reservations and records trips so the business can keep its information in one place.

## Business Question
How many rafting guides and rafts should Montana River Adventures have available each day to accommodate customer demand?

## How to Run
1. Open the App_Final_Project folder in VS Code.
2. Open main.py.
3. Run the Python program.
4. Choose an option from the menu.
5. Choose Save and exit to save all reservations and recorded trips.

## Menu Options
1. View reservations
2. Add or update reservation
3. Record a rafting trip
4. View trip history
5. Save and exit

## Files
- `main.py` - Runs the menu and all program functions.
- `reservations.csv` - Stores customer reservation information.
- `trips.csv` - Stores recorded rafting trips.
- `README.md` - Explains the project and how to use it.
